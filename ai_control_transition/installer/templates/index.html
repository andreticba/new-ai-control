✅ Instalação Concluída!

A orquestração foi finalizada. A infraestrutura base (Bancos, Redis, Ollama, Evolution API) já está rodando via Docker. Para iniciar os serviços locais do AI Control, abra dois terminais e execute:

🖥️ Terminal 1 (Servidor Principal):

# 1. Entre no diretório e ative o ambiente: cd ~/projetos/assistidos/ai-control
source .venv/bin/activate # 2. Ative o kit no projeto (se necessário): bash ~/.vitalia/bin/install-project # 3. (Opcional) Crie um usuário administrador para o painel: python manage.py createsuperuser # 4. Inicie o Django: python manage.py runserver 0.0.0.0:8000

⚙️ Terminal 2 (Tarefas em Background):

# Inicie o worker do Celery para processar integrações pesadas: cd ~/projetos/assistidos/ai-control
source .venv/bin/activate
celery -A config worker -l INFO
